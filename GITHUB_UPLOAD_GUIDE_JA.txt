GitHubへの反映手順（プライバシー更新版）

1. このZIPを解凍します。
2. GitHubで対象リポジトリを開きます。
3. 「Add file」→「Upload files」を選びます。
4. 解凍した `koji-japanese-coaching-main` フォルダの「中身」をすべてドラッグします。
5. 既存ファイルの置換・追加・削除を確認します。
6. Commit message に以下を入力します。
   Privacy update: remove personal name, replace portrait, update email
7. `Commit changes` を押します。
8. Netlifyのデプロイ完了後、日本語ページと英語ページを確認します。

確認する項目
- 本名が表示されていない
- 顔写真ではなくアイコンが表示されている
- メールが japancareer.support@gmail.com になっている
- メールボタンから新しいアドレスが開く
- PC／スマートフォンでヘッダーが崩れていない
- OGP画像が新しいブランド画像になっている

重要：GitHub履歴について
今回の更新で、現在公開されるWebページと最新コミットから個人名・旧写真を削除できます。
ただし、過去のGitコミット履歴には旧ファイルが残る可能性があります。

過去履歴からも完全に消したい場合は、次のいずれかが必要です。
A. 新しいプライベート／公開リポジトリを作り、更新版だけを最初のコミットとして登録する
B. git filter-repo等で履歴を書き換え、force pushする

操作が簡単で安全なのは、新しいリポジトリへ更新版だけをアップロードし、Netlifyの接続先を変更する方法です。

未変更の連絡手段
- WhatsApp電話番号
- LINE URL

匿名性をさらに高める場合は、公開前にこれらも削除してください。
